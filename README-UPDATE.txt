Kiran Creations — Baby Milestone Frame Update

Files:
- index.html: updated website with a new “বেবি মাইলস্টোন” template
- baby-milestone.png: your supplied design, prepared with transparent photo openings

How to publish:
1. Open your GitHub repository:
   https://github.com/kirancreation/kiran-creations-frame-studio
2. Click Add file > Upload files.
3. Extract this ZIP first.
4. Upload BOTH index.html and baby-milestone.png from this folder.
5. Click Commit changes.
6. Wait a few minutes, then refresh:
   https://kirancreation.github.io/kiran-creations-frame-studio/

Important:
- Upload the extracted files, not this ZIP itself.
- Keep both files in the repository root (same level as README.txt).
- Select “বেবি মাইলস্টোন” on the website. The uploaded photo will appear in both circular photo openings.
