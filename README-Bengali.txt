ফাইল: index.html, .nojekyll, baby-milestone.png, love-birthday-calendar.jpg, durga-puja-bengali-frame.png

GitHub Repository-র মূল পাতায় সব ফাইল আপলোড করুন। পুরোনো index.html বদলে নতুন index.html দিন। ছবি ফাইলগুলিও একই মূল পাতায় রাখুন। Commit changes করুন, তারপর GitHub Pages সাইট refresh করুন।

লাভ বার্থডে কোলাজে একটি আপলোড করা ছবি ছয়টি ফটো বক্সে বসে। দুর্গাপূজা ডিজাইনে আপলোড করা ছবি মাঝের ফাঁকা অংশে বসে। মূল ডিজাইনের কিছু লেখা/ডিজাইন baked-in থাকায় সেগুলি আলাদা করে সম্পাদনাযোগ্য নয়।
সংশোধন: লাভ বার্থডে কোলাজের ৬টি ছবির ঘর আলাদা করে মাপ ঠিক করা হয়েছে, যাতে ছবিগুলো একে অপরের ওপর না ওঠে।
