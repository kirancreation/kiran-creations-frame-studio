Kiran Creations Bengali Frame Studio — GitHub Pages

Files
- index.html: the website (self-contained; HTML, CSS, and JavaScript included)
- .nojekyll: tells GitHub Pages not to run Jekyll processing

Publish for free
1. Sign in or create an account at https://github.com/
2. Open https://github.com/new
3. Repository name: kiran-creations-frame-studio
4. Choose Public, then create the repository.
5. In the new repository, choose Add file → Upload files.
6. Unzip this package on your computer, then upload index.html and .nojekyll from the extracted folder (not the ZIP itself).
7. Click Commit changes.
8. Open the repository Settings → Pages.
9. Under Build and deployment, select Deploy from a branch; branch main; folder /(root); click Save.
10. Wait a few minutes. The Pages settings screen will show the website address.

Important
- This is a static website. Photo uploads and PNG export run in the visitor's browser.
- It does not include customer accounts, payment collection, paid-download protection, or a database.
- GitHub Pages sites are public. Do not upload customer photos or private information to the repository. Uploaded photos in the website editor are processed in the visitor's browser and are not sent to a server by this demo.
- Your current Netlify site will not automatically change when you publish this separate GitHub Pages copy.
