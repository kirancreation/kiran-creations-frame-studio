Kiran Creations - Photo Zoom & Move Update

This update adds photo zoom controls and horizontal/vertical positioning sliders.
You can also drag the photo directly on the preview canvas. Controls apply to the photo in all openings (including the six-slot love collage).

To update GitHub Pages:
1. Open your repository: https://github.com/kirancreation/kiran-creations-frame-studio
2. Open index.html and choose Edit (pencil), or choose Add file > Upload files.
3. Replace the existing index.html with this updated file and Commit changes.
4. Keep existing image assets (baby-milestone.png, love-birthday-calendar.jpg, durga-puja-bengali-frame.png) in the repository root.
5. Open the website and press Ctrl+F5.
